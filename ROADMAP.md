# ROADMAP — GUÍA DE BIENESTAR

## REGLA DE TRABAJO

**Todo desarrollo se hace en preview (rama `mejoras`). Nada se activa en producción hasta que el roadmap lo indique.**

---

## FASES

### Fase 1 — Mes 1: Base sólida

**Objetivo:** Revisar y preparar todo lo que ya existe.

- [ ] Revisar mapa, filtros y navegación.
- [ ] Revisar perfiles de facilitadores (contacto, redes, bio).
- [ ] Revisar admin: facilitadores, actividades, planes.
- [ ] Revisar sistema de pago ($11.000).
- [ ] Revisar mobile.
- [ ] Preparar estructura de eventos en admin.
- [ ] Definir técnicamente sistema de "Destacado del mes".
- [ ] Todo nuevo desarrollo → preview.

---

### Fase 2 — Mes 2: Funcionalidades de crecimiento

**Objetivo:** Dejar el sitio preparado para cuando crezca la cantidad de facilitadores.

- [ ] Implementar eventos (carga desde admin, muestra en home y en página propia).
- [ ] Implementar "Destacado del mes" (lógica según plan de pago).
- [ ] Crear sección "Sumate" (explicando el plan de $11.000).
- [ ] Incorporar testimonios reales.
- [ ] Probar todo en preview.

---

### Fase 3 — Mes 3: Escalabilidad

**Objetivo:** Que el sitio esté listo para crecer sin que tengas que correr atrás del desarrollo.

- [ ] Revisar flujo completo de usuario.
- [ ] Revisar flujo facilitador (registro → pago → publicación).
- [ ] Revisar eventos, destacados, filtros.
- [ ] Preparar estructura para nuevos planes de pago.
- [ ] Documentar funcionamiento del admin.
- [ ] Dejar funcionalidades listas para activar.
- [ ] Pasar a producción solo lo que corresponda.
